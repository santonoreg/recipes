# Συνταγές

Facebook post / βίντεο μαγειρικής → συνταγή (υλικά + εκτέλεση) σε site με βίντεο, PDF και εκτύπωση.

- **Backend διαχείρισης** (`/admin`): συνδέεσαι, δίνεις τον σύνδεσμο του post και η συνταγή βγαίνει μόνη της.
  Εκεί γίνεται και η αφαίρεση συνταγών.
- **Frontend** (`/`): λίστα συνταγών με αναζήτηση, σελίδα συνταγής με το βίντεο, **Κατέβασμα PDF** και **Εκτύπωση**.

Τεχνολογίες: PHP 8.2+, SQLite, CSS, JavaScript (χωρίς framework).

**Ροή:** yt-dlp (βίντεο + κείμενο post) → ffmpeg (ήχος + καρέ) → Whisper (ομιλία → κείμενο) →
Claude (κείμενο post + ομιλία + καρέ) → συνταγή στη βάση.

## Εγκατάσταση

```bash
composer install
copy .env.example .env
```

Στο `.env` βάλε το `ANTHROPIC_API_KEY`. Τα υπόλοιπα κλειδιά είναι ίδια με της παλιάς εφαρμογής Python.

Χρειάζονται οι επεκτάσεις PHP `pdo_sqlite`, `gd`, `mbstring`, `curl`.

### Εξωτερικά εργαλεία

Η PHP δεν κάνει μόνη της λήψη βίντεο ούτε απομαγνητοφώνηση, οπότε καλεί τρία εργαλεία:

| Εργαλείο | Για ποιο πράγμα | Ρύθμιση στο `.env` |
|---|---|---|
| yt-dlp | λήψη βίντεο και κειμένου post | `YTDLP_BIN` ή μέσω `PYTHON_BIN` |
| ffmpeg | ήχος και καρέ | `FFMPEG_BIN` ή μέσω `PYTHON_BIN` |
| Whisper (faster-whisper) | ομιλία → κείμενο | `PYTHON_BIN` |

Ο πιο απλός τρόπος είναι ένα Python περιβάλλον που τα έχει όλα:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r tools/requirements.txt
```

Η εφαρμογή βρίσκει μόνη της το `.venv` (ή το `old/.venv`) μέσα στον φάκελό της. Αν το Python είναι αλλού,
γράψε τη διαδρομή του στο `PYTHON_BIN`. Χωρίς Whisper οι συνταγές βγαίνουν κανονικά, αλλά μόνο από το κείμενο
του post και την εικόνα.

## Εκκίνηση

**Τοπικά, για δοκιμή:**

```bash
php -S localhost:8765 -t public public/index.php
```

**Laragon / Apache:** βάλε τον φάκελο στο `www`. Το ριζικό `.htaccess` προωθεί τα πάντα στο `public/`, οπότε
δουλεύει είτε το vhost δείχνει στον ριζικό φάκελο είτε στο `public/`, και σε υποφάκελο (π.χ. `localhost/recipes`).
Θέλει ενεργό `mod_rewrite`.

**Server χωρίς `.htaccess` / `mod_rewrite`:** δεν χρειάζεται καμία ρύθμιση στον web server. Το ριζικό `index.php`
αναλαμβάνει την αρχική (π.χ. `example.gr/recipes/`) και οι υπόλοιπες σελίδες παίρνουν τη μορφή
`example.gr/recipes/index.php/recipe/3`. Επειδή τότε ο φάκελος της εφαρμογής σερβίρεται ολόκληρος, όρισε στο `.env`
`DATA_DIR` (και προαιρετικά `OUTPUT_DIR`) σε διαδρομή έξω από τον φάκελο του web.

**nginx:** όρισε `root` το `public/` και `try_files $uri /index.php$is_args$args;`.

Οι φάκελοι `data/` και `output/` πρέπει να είναι εγγράψιμοι από τον web server.

## Πρώτη σύνδεση

Άνοιξε το `/admin`. Την πρώτη φορά σου ζητά να φτιάξεις τον λογαριασμό διαχειριστή. Αυτό γίνεται μόνο από τον
ίδιο τον υπολογιστή (localhost). Σε server, ή για αλλαγή κωδικού:

```bash
php bin/create-admin.php <όνομα χρήστη>
```

## Νέα συνταγή

Στο `/admin` υπάρχουν τρεις τρόποι:

1. **Σύνδεσμος post**: επικόλλησε τον σύνδεσμο και πάτα **Βγάλε τη συνταγή**.
2. **Αρχείο βίντεο**: ανέβασε βίντεο από τον υπολογιστή (mp4, mov, webm, mkv, avi).
3. **Καταγραφή οθόνης**: όταν το post δεν κατεβαίνει, ο browser καταγράφει την καρτέλα όπου παίζει το βίντεο,
   μαζί με τον ήχο της. Θέλει Chrome ή Edge και `localhost` ή https.

Και στους τρεις μπορείς να επικολλήσεις το κείμενο του post, αν τα υλικά είναι γραμμένα εκεί.
Η επεξεργασία τρέχει στο παρασκήνιο και η πρόοδος φαίνεται στις «Εργασίες».

## Ιδιωτικά posts / ομάδες

Ρύθμισε `COOKIES_BROWSER=firefox`, ώστε το yt-dlp να χρησιμοποιεί τη σύνδεσή σου, ή εξήγαγε `cookies.txt`
και βάλε τη διαδρομή του στο `COOKIES_FILE`. Αν τίποτα δεν δουλέψει, υπάρχει η καταγραφή οθόνης.

## Δεδομένα

| Τι | Πού |
|---|---|
| Βάση SQLite (συνταγές, εργασίες, διαχειριστής) | `data/recipes.sqlite` |
| Βίντεο και φωτογραφία κάθε συνταγής | `output/ΕΕΕΕΜΜΗΗ-ωωλλδδ/` (`OUTPUT_DIR`) |
| Αρχεία καταγραφής του worker | `data/logs/` |

Για αντίγραφο ασφαλείας αρκούν οι φάκελοι `data/` και `output/`.

Εισαγωγή συνταγών από την παλιά εφαρμογή Python:

```bash
php bin/import-old.php old/output
```

## Γλώσσες και κόστος

Το βίντεο και το κείμενο του post μπορεί να είναι σε οποιαδήποτε γλώσσα. Η συνταγή βγαίνει στη γλώσσα του
`OUTPUT_LANGUAGE` (προεπιλογή: Ελληνικά).

Ένα βίντεο ~5 λεπτών με ~30 καρέ κοστίζει περίπου 0,10–0,25 $ με το `claude-opus-5-5`.
Για φθηνότερα, βάλε `CLAUDE_MODEL=claude-haiku-5-5` ή μείωσε το `MAX_FRAMES`.

## Δομή

```
public/      web root: index.php, CSS, JavaScript
src/         κώδικας PHP (δρομολόγηση, ροή επεξεργασίας, βάση, PDF)
templates/   σελίδες και πρότυπο PDF
bin/         worker παρασκηνίου, δημιουργία διαχειριστή, εισαγωγή παλιών συνταγών
tools/       transcribe.py (Whisper) και τα πακέτα Python των εργαλείων
```
